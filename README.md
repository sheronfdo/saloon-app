# Saloon App

A Flutter-based salon booking application designed to streamline appointment scheduling and enhance the customer experience.

## Features

- **User Authentication**: Secure login and registration functionalities.
- **Appointment Booking**: Browse available services and schedule appointments with preferred stylists.
- **Real-time Notifications**: Receive updates on booking confirmations and reminders.
- **Profile Management**: Update personal information and view booking history.
- **Admin Panel**: Manage services, staff, and monitor appointments.

## Technologies Used

- **Flutter**: Cross-platform UI toolkit for building natively compiled applications.
- **Dart**: Programming language optimized for building mobile, desktop, and web applications.
- **Firebase**: Backend services including authentication, cloud firestore, and real-time database.

## Getting Started

### Prerequisites

- Flutter SDK installed.
- An editor like VS Code or Android Studio.
- Firebase account for backend services.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/sheronfdo/saloon-app.git
   ```


2. Navigate to the project directory:
   ```bash
   cd saloon-app
   ```


3. Install dependencies:
   ```bash
   flutter pub get
   ```


4. Configure Firebase:
   - Follow the [Firebase setup guide](https://firebase.google.com/docs/flutter/setup) to integrate Firebase with your Flutter app.
   - Replace the existing `google-services.json` and `GoogleService-Info.plist` files with your own.

5. Run the application:
   ```bash
   flutter run
   ```

